Project Description

This project is a simple AI system for the Advanced Artificial Intelligence course (MSC520). The system plays Tic-Tac-Toe against the user using the Minimax algorithm.

Problem: Design an AI agent that never loses in a 3×3 Tic-Tac-Toe game.

Algorithm: Minimax searches all possible moves and assigns a score: +1 for an AI win, −1 for a human win, and 0 for a draw. The AI chooses the move with the best score.

Implementation: The frontend is built using HTML, CSS, and JavaScript. The backend is implemented in Python using Flask. The browser sends the current board to the server, and the server returns the best AI move.

Evaluation: For any valid sequence of moves from the user, the AI does not lose: the outcome of the game is either an AI win or a draw.
